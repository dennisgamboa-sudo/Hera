# EYEHERA · Control Center

Tu app personal de control. **100% local, sin servidores, sin cuentas.** Todos tus datos viven en tu dispositivo.

## ⚠️ Importante: GitHub muestra el código, no la app

El link de GitHub te lleva al **código fuente** (texto), no a la app funcionando.
Para usarla necesitas **abrir el archivo en un navegador**. Tienes 2 opciones:

### Opción A — Link permanente (GitHub Pages) · la mejor
Una sola vez, activa GitHub Pages en el repositorio:
1. En GitHub, ve a tu repo → **Settings** → **Pages**
2. En "Branch" elige `claude/instagram-growth-strategy-kWtSQ` y carpeta `/ (root)` → **Save**
3. Espera ~1 min. GitHub te da un link tipo:
   `https://<tu-usuario>.github.io/Hera/app/`
4. Abre ese link en el móvil → **funciona como web real** → añádelo a la pantalla de inicio.

### Opción B — Descargar el archivo (rápido, sin configurar nada)
1. En GitHub abre `app/index.html`
2. Toca el botón **"Download raw file"** (o "⋯" → Download) para bajarlo al teléfono
3. Abre el archivo descargado con Safari/Chrome desde tu carpeta de Descargas

### Convertirla en app de pantalla de inicio
Una vez abierta en el navegador:
- **iPhone (Safari):** botón Compartir ↑ → "Añadir a pantalla de inicio"
- **Android (Chrome):** menú ⋮ → "Añadir a pantalla principal"

Aparecerá un ícono como cualquier app. Tus datos quedan guardados ahí.

## Primer arranque — carga tus datos
1. Abre la app → toca **⚙︎** (arriba a la derecha)
2. Toca **"✦ Cargar datos iniciales"**
3. Listo: arrancas con tus 6 posts, el baseline (22 seg · 9,597 vistas) y ~40 creadores.

## Recordatorios / alarmas
Toca **🔔** arriba a la derecha:
- Ajusta las horas de tu rutina (publicar, responder, comentar, registrar)
- **"⬇ Descargar alarmas (.ics)"** → ábrelo y se añaden a tu calendario; suenan **aunque la app esté cerrada** y se repiten cada día (esto es lo fiable en móvil)
- "Activar avisos de hoy" → notificaciones del navegador mientras la app está abierta

## Qué hace

| Pestaña | Para qué |
|---------|----------|
| **◎ Hoy** | El cerebro. Analiza tus datos y te dice qué hacer, qué falta y qué mejorar hoy. |
| **📈 Métricas** | Registra seguidores, vistas, engagement y saves. Ve tu progreso hacia 10k y la tendencia. |
| **🎬 Contenido** | Planifica posts (idea → listo → publicado). Descubre automáticamente tu mejor formato. |
| **👥 Comunidad** | Tu lista de 100 creadores + contador diario de comentarios (meta: 5/día). |
| **✎ Plantillas** | Captions de LUCKY y comentarios para creadores, listos para copiar. |

## El motor de recomendaciones

Cada vez que abres "Hoy", la app revisa tus números y prioriza alertas:
- 🔴 Días sin publicar (constancia del algoritmo)
- ⚠️ Engagement bajo → mejora captions
- 👥 Comentarios diarios pendientes
- 📉 Crecimiento estancado → activa comunidad
- ⭐ Qué está funcionando → replícalo

## Tus datos

- Se guardan automáticamente en el navegador (localStorage).
- Toca **⚙︎** arriba a la derecha para **exportar un respaldo JSON**. Hazlo cada semana.
- Puedes importar el respaldo en otro dispositivo o restaurarlo cuando quieras.

> Si borras el historial del navegador o la caché del sitio, pierdes los datos. Por eso: **exporta respaldos**.
